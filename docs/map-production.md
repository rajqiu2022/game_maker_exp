# 聚落、河道与出入口制作手册

适用于玩家能自由走动、近身交谈、调查和跨门的俯视或 2.5D 地图。白模阶段先用角色从入口走完一件事，再安排沿途看到的建筑。发行前用目标平台的正常存档重走同一条路。通用作者规格、分层和构建流程见[地图场景生成管线](map-scene-pipeline.md)。

## 先画玩家要走的路

在图纸上写下当地靠什么生活、今天发生了什么，以及玩家进来要办什么事。以刚封渡的货埠为例，船还在，桨已被收进岸棚，守渡人能看住跳板。玩家沿卸货路走到封绳前，自然会停下来调查。若把同一艘船放在无路可达的远岸，它只能交代风景。

给路线画出进场方向、第一眼能看见的地标、实际交互侧、门槛和回程脚点。把玩家和队友按运行比例摆上去，再把图交给场景美术。使用生图时，把路面、门前落脚区、桥面与视线缺口标在布局参考图上，复核新图是否在这些地方多画了柱、货堆或树干。可复制下表到单图制作单。

| 填写项 | 有封锁的渡口示例 |
|---|---|
| 玩家从哪来，进来想做什么 | 从村道来，沿装卸坡找封渡痕迹，再问守渡人 |
| 玩家沿路看到什么 | 岸棚收桨、封绳横在跳板前；岗哨能看到入口 |
| 谁在哪干活 | 脚夫往返货堆与棚口；守渡人站在能交谈又能看船的一侧 |
| 哪些状态改变通路 | 封渡时可走到绳前；开门后旧横木处可走，横木停放处有阻挡 |
| 怎么走回去 | 由内向外穿门，落在门前可走区，空手再走一次进门路线 |

## 让街面、院墙和人有来处

- **按营生排门面。** 茶市可以沿收茶、过秤、装车、候船排成一条街。繁忙感来自货物和人在几个工位之间流动。冷清的渡口可以沿用同样的铺棚，只收起秤、系住船，把人留在查验点。
- **画出院墙围住的东西。** 在布局上沿墙从一端描到另一端，标出接到哪栋门房、哪个院角或哪段崖壁。从玩家进场方向看一次接缝。街口若本来敞开，保留开口，连同多余短墙一并清理旧碰撞。
- **让铺面顺着使用痕迹变化。** 门前铺石接台阶，车辙从仓门延到卸货位，人流转弯处留开阔面。用碎石、土肩、磨损和不规则边沿过渡。靠尺修砌的驳岸或院内石阶可以有直边。用角色镜头检查，尤其看大块矩形换材质的边界。
- **按岗位布置人物。** 为巡逻者记录两端作业点、折返点和对话接近点；用移动距离校步幅，减速转身和停谈时一起收步。玩家从人物两侧靠近都要看得到脚和交互提示。用同镜头主角核对成年人的身高，坐姿、伤员、孩子各用相应参照。

## 把水面、岸线和桥做成同一条河

1. 在弯道、桥孔、泊位和浅滩布横断面，给每个断面定下左右岸。连成水面边界，同一批点也用于浅岸表现与水陆阻挡。码头伸入水中的栈板、可走桥面单列通行范围。
2. 对每段河面取沿河长度和横跨河宽的位置。沿河长度驱动水纹相位，纹理运动方向取该段切线；在相邻断面间连续插值，避免水纹在弯角折断。按距岸距离平滑降低位移速度，在收窄的桥孔局部加快；浅水中的石头固定在河床上。
3. 把桥台放到实岸上，从两岸分别上桥，再沿两侧桥边试走进水。泊船、岸棚和芦苇可遮住接缝，也要从反方向走回检查露出的岸角。静水池可用轻微涟漪；有闸墙的人工水道可保留规则几何。
4. 固定镜头录一小段，选桥下一道亮纹与贴岸一道亮纹，记录同一时段的位移和方向。截图能查桥台接岸，视频才能查转弯、流速差及岸石是否跟着水漂。更换分辨率、相机缩放后要重新比较。

## 对齐画面、脚点和游戏状态

把视觉、可走面、实体阻挡、交互范围、跨图门及其返程点分别标出，写明使用的坐标系。背景发生平移、裁切或缩放时，脚点、提示箭头、小地图和交互热区需经过同一坐标变换。

| 遇到的问题 | 制作与验证 |
|---|---|
| 门口有箭头却进不去，或箭头浮在屋顶 | 单列可见门阶、玩家触发区域和另一侧返回点。从街上步行进门，完成一次店内操作，出门后松开按键，再进一次。返程点要留出角色占地，并避开立即重触发的区域。 |
| 画面看似开放却过不去 | 将拒马、横木等可移动物的阻挡随同一状态移动。记录原址、新址各一点，放行前后交叉验证；保存后重启，再经此处通行。 |
| 人在房内或被屋顶裁去下半身 | 建筑用基座参与阻挡，普通人物按脚底排序。烘焙地图需要屋顶淡出时，准备移除该屋顶的干净底图和同坐标独立前景；前景轮廓负责遮盖，地上可达的脚点区域负责触发淡出。分别从前后经过，并在离开后检查恢复。 |
| 单张图能加载，玩家从上一图到不了目标 | 在实际存档阶段，从入口以角色占地检查整条路。分别记录可走点、应阻挡点、交互接近点和双向门。剧情单向门另外写开放条件；旧存档落脚被新建筑占用时，在原街区附近找安全点再回访。 |

## 大图的清晰度与滚动开销

在目标分辨率和常用缩放下，沿同一路段分别截静帧、录一段移动。静帧里门槛已经模糊时，核对源图有效像素和采样过滤；只有滚动时发抖或丢帧时，记录相机位置、帧时间峰值和纹理上传。固定地表、独立前景和动态人物可分别检查。大块不透明底图可用 RGB，可淡出的屋檐则需要透明通道。把景深较强、道路边界难以辨认的构图用于载入插画，可行走版本保留清楚的脚点和门阶。

## 从白模到发行包

首次白模至少要能从门口走到第一交互点并回来。发行验收再加上实际任务前后、旧档冷读和同机位截图。记录存档阶段、包版本、镜头缩放、路线和结果；标明哪些路段用了定点定位，哪些是实际步行。改造旧图时沿用已有地图、任务和门的标识，先把一个问题点及其返程接入原规格，再逐图补测。[地图发布检查表](../checklists/map-release.md) · [三个实测案例](../case-studies/wuxia-settlements-and-waterways.md)
