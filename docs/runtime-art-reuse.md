# 从现有美术到可交付的游戏资源

## 先找正在使用的那一份

从玩家看见的界面反查场景、消费者、资源路径和原图。登记用途、作者或来源、授权范围、像素尺寸、裁切或帧序、脚点，以及在哪个发行版本里验证过。候选、预览和废弃版本要能从目录中辨认出来。遇到同名文件先比 SHA-256。像素相同的文件仍可能有不同的朝向、锚点或授权条件。

| 需求 | 适合复用的部分 | 采用前要实际看什么 |
|---|---|---|
| 对话立绘、属性头像和小地图头像 | 引用同一张已采用立绘，在资源上定义脸部裁切区 | 半身、头像、圆形小图分别按最终显示尺寸查看。图集子区域的坐标要换算回整张图 |
| 城镇和野外小地图 | 用实景的地形、铺路纹理、建筑位置生成局部底图，另绘标记和迷雾 | 在同一存档、同一位置看路口、屋檐和桥头，实际走一段后存档、退出并重读 |
| 刀招、暗器和人物受击 | 同种兵器可共享特效素材，每个角色保有自己的动作帧、握点和朝向 | 双方交换方向，逐段检查蓄势、出手和收招；站立受击和倒地各截一帧 |
| 图标和多帧特效 | 按语义和资源 ID 选择已授权的运行图，保留帧序与推荐节奏 | 在背包最终尺寸检查轮廓，在战斗中检查首帧、末帧和裁边 |

## 取用已收录的图标和特效

以下例子选择一件线索物品图标与一套刀招。先在[资源目录](../resource-packs/ink-wuxia-icons-vfx-v1/CATALOG.md)确认语义和外观，并核对[包内授权](../resource-packs/ink-wuxia-icons-vfx-v1/LICENSE-ASSETS.md)。在经验库根目录运行，第二个路径换成目标项目中的新目录。

```powershell
python tools/export_pack_selection.py resource-packs/ink-wuxia-icons-vfx-v1 ../MyGame/art/selected-wuxia item_broken_mask vfx_blade_black_wind_01
```

导出工具按资源清单校验每张运行图的 SHA-256，然后一起写入图片、包内授权和 `selection.json`。目标目录已存在时会停止。更新时先导出到新的并列目录，比对版本和校验值后再切换引用。刀招例图每帧 384×384，按左上、右上、左下、右下播放；把整幅图按横向四格截取会切断动作。业务数据应保存稳定 ID，预览图留在经验库供选型。[导出工具](../tools/export_pack_selection.py)

## 从发行包复核

一个 2D RPG 的旧小地图在 1080p 下只显示约 243×162 像素，虽然中原底图已有 3072×2048，探索遮罩覆盖整图却只有 60×60。扩大局部显示、用实景重采样城镇、独立提高遮罩精度后，同一个位置可以辨认屋檐和铺路细节。用旧档逐一核对 267 个已揭开的格子，再步行、存档和重启，比对保存的遮罩。这些尺寸是该项目的实测条件。其他项目应按自己的相机、窗口大小和目标设备重新取样。

交付时从干净检出的源码恢复大文件、执行引擎导入，再核对构建清单。带字节校验的地图和脚本要保留原始换行。检查语音导入映射、动态查找的资源和旧存档仍引用的资源，最后从正式入口在发行包里走到消费者处。通用规则和工具可跨项目使用，具体角色立绘及来源受限的素材按各自授权保留在原项目。
