# 音效发布检查表

## 资源与配置

- [ ] 核心语义事件都有候选音效或明确静默设计。
- [ ] 施法、释放、命中和强化阶段按需要分离。
- [ ] 资源、总线、回退和空间化引用有效。
- [ ] 每个高频并发组有声道上限、冷却和超限策略。

## 运行检查

- [ ] 高频普攻、溅射和群怪场景无刺耳堆叠。
- [ ] 关键警报不会被普通脚步或命中音淹没。
- [ ] 远程事件按 ID 去重，本地预测不会重复播放。
- [ ] 手机扬声器、耳机和桌面设备响度层次可接受。

## 证据

- [ ] 保存峰值声道、限流数量和音频线程告警。
- [ ] 缺失资源回退不会阻塞技能、拾取或 UI 操作。
