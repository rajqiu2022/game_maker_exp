# 手机 UI 发布检查表

## 布局

- [ ] 刘海、圆角、系统手势区和主流长宽比已覆盖。
- [ ] 玩家/队友状态、目标、摇杆和技能区不重叠。
- [ ] 装备槽、页签、列表和详情面板不会互相遮挡。
- [ ] 弹窗超出安全区时可滚动或自适应。

## 触控

- [ ] 核心触控目标至少约 `44–48 dp`，并在真机显示命中矩形检查。
- [ ] 可见图标与触控区域分离，相邻按钮不会误触。
- [ ] 宝箱、建筑、Boss 入口和商店按钮可在角色静止时点击。
- [ ] 面板打开时世界输入被阻止，关闭后恢复。
- [ ] 左右上下和对角摇杆向量长度一致。

## 技能

- [ ] 未学习、已装备、冷却、资源不足和瞄准状态区分清楚。
- [ ] 被动技能可见、不可点击并标记“被”。
- [ ] 拖拽显示正确范围，移到取消区后松手不会施法。
- [ ] 多指或系统中断时能清理瞄准状态。

## 数据与联机

- [ ] 技能、装备、背包、等级、生命和基地状态来自权威快照。
- [ ] UI 使用稳定玩家 ID，不依赖队伍列表顺序。
- [ ] 面板只在操作玩家本地打开。
- [ ] 断线有提示；重连后完整快照覆盖陈旧状态。
- [ ] PC 主机和手机远程玩家完成技能、装备、拾取、建筑、商店和活动入口流程。
