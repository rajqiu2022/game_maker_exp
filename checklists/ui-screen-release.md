# UI 界面发布检查表

配套手册：[数据驱动游戏 UI 生产手册](../docs/ui-production-playbook.md)；配置起点：[UI 界面契约模板](../templates/ui-screen-contract.template.json)。

## 契约与状态

- [ ] 界面用途、数据来源、稳定选择键和命令已声明。
- [ ] 空、正常、选中、已装备、禁用、加载、失败和长文本状态已覆盖。
- [ ] UI 禁用与数据层命令拒绝使用同一规则或可追溯原因。
- [ ] selected、equipped、quality、disabled 没有共用同一种高亮。
- [ ] 操作成功、失败和取消不会产生重复或矛盾状态。

## 概念图与运行资产

- [ ] 数据界面没有直接使用带伪文字、示例数字或固定条目的整屏概念图。
- [ ] 背景、可伸缩面板、重复槽、按钮、图标和装饰已拆分。
- [ ] 动态中文、数值、列表、奖励和状态由引擎绘制。
- [ ] normal/pressed/disabled 与当前输入档所需的 hover/focus 状态同画布、同尺寸、同 bbox、同 alpha mask。
- [ ] disabled 仍有正式底框；hover 不冒充 selected。
- [ ] 九宫格 margin 未拉伸角饰、暗边或文字。
- [ ] 运行资产有来源、版本、处理步骤和采用状态。

## 布局与层级

- [ ] 使用容器、锚点和最小尺寸，不依赖大量绝对坐标。
- [ ] 世界、HUD、系统面板和模态层级隔离。
- [ ] 一次只有一个主要面板接收输入，模态框阻止世界穿透。
- [ ] 列表行高稳定；长名称不会撑坏格子或按钮。
- [ ] 详情、阅读和长列表超过区域时可滚动。
- [ ] 关闭按钮位于内容之上，Esc/返回键可退出。
- [ ] 缺失正式图片时仍有可操作、语义正确的回退。

## 文字与本地化

- [ ] 正式图片没有乱码、假字或不可变业务文案。
- [ ] 标题、正文、标签、禁用文字和 Tooltip 使用统一 Token。
- [ ] 最长中文、空文本、多行说明和极端数字已测试。
- [ ] 正文未依赖小字号粗体建立层级。
- [ ] 正常观看距离可读，不靠放大截图判断。
- [ ] 术语统一，没有开发枚举、内部 ID 或多套名称混入玩家界面。

## 图标、头像和品质

- [ ] 图标在实际显示尺寸仍能辨认类型。
- [ ] 缺图回退按语义/槽位分类，不使用无关通用图标。
- [ ] 列表和详情共用同一头像或头肩裁切逻辑。
- [ ] 方形、3:4、2:3 源立绘的头像裁切均已检查。
- [ ] 品质颜色来自唯一色板，并在列表、详情、商店、Tooltip 和日志一致。
- [ ] 品质内框在 selected/equipped 状态下仍可见。

## Tooltip、阅读和模态

- [ ] 短句使用默认 Tooltip，多属性内容使用结构化面板。
- [ ] Tooltip 有明确最小/最大宽度、内边距和 viewport 钳制。
- [ ] 1、5、10 条属性以及屏幕四角位置均测试。
- [ ] 空内容不会生成空 Tooltip。
- [ ] Tooltip 忽略鼠标事件，不阻断其下方交互。
- [ ] 阅读长文可滚动、重复打开一致，关闭不隐式消耗物品或推进任务。
- [ ] 确认框的接受、拒绝、Esc 和外部关闭行为明确且幂等。

## 操作反馈

- [ ] 普通使用和确认使用汇入同一业务调用路径。
- [ ] 恢复、成长、装备、卸下、净化和失败都有明确反馈。
- [ ] 永久成长区分上限变化与当前值变化。
- [ ] 无数值变化的状态解除仍显示具体结果。
- [ ] 失败不播放成功动画、不扣资源、不静默关闭。
- [ ] 动画和音效绑定实际事件点，完成信号覆盖完整时间轴。
- [ ] 呼吸、悬浮和强调动画不会移动角色/控件的稳定锚点。

## 输入

- [ ] 鼠标主/次操作语义可发现，右键操作有文字提示。
- [ ] 键盘/手柄焦点顺序合理，焦点不会落到隐藏或禁用控件。
- [ ] 触控命中区与视觉尺寸分离，满足目标平台最小尺寸。
- [ ] 面板打开时方向键、确认键和触控不会误操作世界。
- [ ] 面板关闭后输入层完整恢复。

## 自动验证

- [ ] 配置可解析，ID 唯一，资产引用存在。
- [ ] 按钮状态尺寸、alpha 和 bbox 一致。
- [ ] 语义状态矩阵和命令拒绝原因有测试。
- [ ] Tooltip、模态和输入隔离有运行时测试。
- [ ] 缺图、空数据、异常值和超长文本不会崩溃。
- [ ] 引擎 editor/headless 解析和目标 UI 测试场景通过。

## 截图与人工验收

- [ ] 主设计分辨率、窄屏和目标移动设备已截图。
- [ ] 空、正常、长文本、极端数量、禁用和错误状态已截图。
- [ ] 当前输入档适用的 hover/focus，以及 pressed、selected、equipped、Tooltip 和模态已截图。
- [ ] 调试 UI 默认隐藏；调试面板使用单独证据图。
- [ ] 截图记录界面、状态、分辨率、版本和稳定对象 ID。
- [ ] 人工确认信息层级、可读性、语义、节奏和视觉一致性。

## 完成口径

最低可用：核心流程可完成，数据正确，文字可读，空/错/禁用状态可解释，输入不穿透。

正式发布：资产可追溯；状态、布局、输入和反馈一致；自动门禁、截图矩阵和目标设备验收均有证据，已知例外有负责人和处理计划。
