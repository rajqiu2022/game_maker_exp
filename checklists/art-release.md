# 美术资产发布检查表

## 契约与来源

- [ ] 资源用途、视角、光向、画布、最终尺寸和透明要求已记录。
- [ ] AI 模型/素材来源、生成日期、提示词版本和参考图使用方式可追溯。
- [ ] 未记录密钥、机器绝对路径和无授权第三方资源。
- [ ] 项目负责人已确认生成模型、字体、音频和参考素材许可。

## 处理

- [ ] 原始图、中间结果、QA 报告和发布目录分开。
- [ ] 去底后无黑底、键色边缘、孔洞和大块残留。
- [ ] 画布、比例、锚点和颜色模式已归一化。
- [ ] 新资源进入新版本目录，没有直接覆盖已发布版本。
- [ ] 发布清单记录处理管线版本和文件哈希。

## 质量

- [ ] 对应专题的尺寸、alpha、连通块、帧数或接缝 QA 通过。
- [ ] 在真实游戏背景和实际显示尺寸下完成视觉验收。
- [ ] 与项目现有资产的视角、材质、轮廓和光向一致。
- [ ] PC、手机或目标低画质档都完成预览。
- [ ] 失败资源和 source 目录不会进入正式导出包。
