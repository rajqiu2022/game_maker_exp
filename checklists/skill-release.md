# 技能发布检查表

## 数据

- [ ] 技能 ID、名称、分类、学习等级、冷却和资源消耗完整。
- [ ] 每级效果数值和目标形状可由权威端验证。
- [ ] 被动技能不进入主动施法流程。
- [ ] 技能定义只引用 `presentation_id`，不硬编码具体资源。

## 表现

- [ ] 图标、通用角色动作、施法/命中 VFX 和 SFX 分别配置。
- [ ] 方向、显示范围和真实命中范围一致。
- [ ] 不同职业的轮廓、颜色、节奏和音色可区分。
- [ ] 高频普攻、溅射和多目标命中音效已限流。
- [ ] 缺失资源可安全回退且只警告一次。

## 输入与联机

- [ ] PC 键鼠释放正常。
- [ ] 手机按下、拖动、范围预览、取消区和松手释放正常。
- [ ] 权威端唯一执行扣资源、冷却和效果结算。
- [ ] 远程客户端只播放标准化表现事件。
- [ ] 重复表现按 `event_id` 丢弃；有序通道再用 `event_seq` 检测缺口。
- [ ] 学习/换槽后主机与远程玩家的 HUD 状态一致。

## 手感

- [ ] 伤害事件与攻击/施法命中时刻一致。
- [ ] 大招不是简单放大普通特效。
- [ ] 命中、暴击、溅射和减甲都有可识别反馈。
- [ ] 目标设备上特效不遮挡关键战斗信息。
