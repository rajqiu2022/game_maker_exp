# 装备成长检查表

## 路线

- [ ] 每个职业有起步、过渡、核心和终局方向。
- [ ] 前期过渡装备不依赖 Boss 或高难挑战材料。
- [ ] 已有低阶装备能参与后续升级或有明确回收用途。
- [ ] 推荐排序考虑职业、等级、已拥有和可打造状态。

## 数据与交互

- [ ] 物品、配方、掉落和前置引用无缺失或循环。
- [ ] 非本职业装备保持在地面并显示名称、品质和职业提示。
- [ ] 未知物品不会被删除、扩张格子或污染背包。
- [ ] 购买、打造、装备和快捷槽由权威端修改且可去重。

## 实玩

- [ ] 每个职业从空背包完成一次前期成长流程。
- [ ] 联机重连后装备、材料、金币和快捷槽一致。
