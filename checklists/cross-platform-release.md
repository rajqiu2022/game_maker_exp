# 跨平台发布检查表

## 构建

- [ ] 桌面与移动产物来自同一提交、协议和内容版本。
- [ ] 从可复现导入状态构建，不依赖开发机残留缓存。
- [ ] 入口资源闭包、产物清单和哈希已生成。
- [ ] 包后审计确认文件存在、大小写一致、无开发文件。

## 联机兼容

- [ ] 房间公布稳定地图 ID 与当前地图闭包摘要。
- [ ] 只缺少未参与联机的其他地图时仍可加入。
- [ ] 协议或当前地图依赖不一致时给出明确原因。

## 设备冒烟

- [ ] 桌面端完成冷启动、建房和一轮核心玩法。
- [ ] 移动端完成冷安装、加入和触控核心流程。
- [ ] 保存包名、版本、哈希、设备与结果。
