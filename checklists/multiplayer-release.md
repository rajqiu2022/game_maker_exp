# 多人联机发布检查表

## 自动检查

- [ ] 请求包含稳定身份、请求 ID、对象 ID 和协议版本。
- [ ] 重复请求只生效一次，乱序修订不会覆盖新状态。
- [ ] 等级、装备、背包、技能槽、基地生命可完整序列化恢复。
- [ ] 面板打开、选中项和拖拽状态不进入世界广播。
- [ ] 当前地图闭包兼容握手有成功与失败测试。

## 双设备流程

- [ ] 远程玩家可学习、释放技能并看到冷却与资源变化。
- [ ] 拾取、宝箱、建筑、商店、打造和活动入口均可操作。
- [ ] 主机与远程玩家看到一致的等级、背包和基地状态。
- [ ] 一个玩家打开面板时，其他玩家界面不变化。
- [ ] 网络中断有提示；恢复、重连或退出符合产品声明。

## 证据

- [ ] 保存双方日志、设备信息、版本、地图 ID 和测试时长。
- [ ] 记录不支持的主机迁移或重连边界。
