# 角色与怪物精灵发布检查表

## 完整性

- [ ] `idle`、`walk`、`attack`、`hit`、`death` 动作完整。
- [ ] 所需上、下、左、右方向完整或有明确镜像规则。
- [ ] 帧文件、帧数、FPS、循环和命中帧与清单一致；命中帧声明从 0 还是从 1 计数。
- [ ] 运行时引用稳定 `art_id`，不是业务 ID 拼路径。

## 图片质量

- [ ] 所有帧尺寸和 RGBA 模式一致。
- [ ] 四角透明，无黑底、绿边、网格线和文字。
- [ ] 主体主要连通块完整，没有被裁掉的脚、武器或头部。
- [ ] 脚底基线、身高和缩放稳定。
- [ ] 相邻帧不是重复静态图。

## 动画与方向

- [ ] 移动时身体确实朝对应方向，不只是水平翻转脸部。
- [ ] 停止移动后保留最后朝向。
- [ ] Attack 有起手、命中、收招，伤害绑定命中帧。
- [ ] Hit 能被看到且不会卡住状态机。
- [ ] Death 只播放一次，不会被 walk/idle 覆盖。

## 视觉层级

- [ ] 普通、精英、Boss 的轮廓、装备、动作重量和尺寸可区分。
- [ ] Boss 不是普通怪简单放大。
- [ ] 在真实地图背景和游戏实际显示尺寸下可读。
- [ ] 血条、选择圈、碰撞体与视觉尺寸匹配。
