# 建筑交互与遮挡检查表

- [ ] 视觉、碰撞脚座、交互区域和淡化区域分别配置。
- [ ] 建筑节点原点位于门槛或脚座，不使用图片中心排序。
- [ ] 玩家进入遮挡区时只淡化视觉，不禁用碰撞或交互。
- [ ] 半透明状态仍能识别建筑，角色脚底清晰可见。
- [ ] 快速进出时 tween 不闪烁、不积累。
- [ ] 多名覆盖角色使用对象集合或引用计数。
- [ ] 角色销毁或断线后覆盖状态可以清理。
- [ ] PC 键鼠和手机上下文按钮都能交互。
- [ ] 权威端重新验证距离、区域和建筑状态。
- [ ] 面板只在发起交互的本地玩家打开。
- [ ] 建筑世界状态变化能同步给其他玩家。
- [ ] 关闭按钮位于内容之上，触控区域足够大。
