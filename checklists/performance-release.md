# 性能发布检查表

## 场景与预算

- [ ] 明确最低目标设备和正式资源峰值场景。
- [ ] 记录帧时间分位数、最长帧、内存、节点和纹理占用。
- [ ] 生成批次、活动实体、路径查询、粒子和声道均有上限。
- [ ] 预热、采样时长与事件标记可复现。

## 压力流程

- [ ] 冷启动后首次刷怪不会阻塞输入。
- [ ] 高攻速、群伤、飘字与音效同时出现仍在预算内。
- [ ] 联机快照峰值和远程表现没有明显卡顿。
- [ ] 长时运行后无持续内存增长、过热或严重降频。

## 证据

- [ ] 保存优化前后同场景报告和采样文件。
