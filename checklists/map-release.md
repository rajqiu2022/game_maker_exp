# 地图发布检查表

## 规格与构建

- [ ] 地图只有一个可编辑作者规格。
- [ ] 生成物可以删除后完整重建。
- [ ] 构建使用稳定随机种子并记录规格/工具版本。
- [ ] ID 唯一，任务、掉落、建筑、触发器和资源引用有效。
- [ ] 当前联机地图及其依赖摘要在各平台一致。

## 空间与玩法

- [ ] 玩家出生点不在建筑、基地或阻挡体内。
- [ ] 关键路线可达，视觉、碰撞和导航没有明显错位。
- [ ] 活动区内外的攻击、寻敌、投射物和队友规则一致。
- [ ] 远处营地按距离激活，刷怪有存活上限和批次预算。
- [ ] Boss、宝箱、建筑和出口都有可读入口提示。

## 视觉

- [ ] 背景地形不参与实体 Y 排序。
- [ ] 高物体使用脚底锚点，前景不遮住角色脚底。
- [ ] 各区域有不同但统一的地形、地标和生态语言。
- [ ] PC、手机和低内存档保留相同玩法坐标与对象 ID。
- [ ] 小地图标记与世界对象一致。

## 验证

- [ ] 规格校验和预览通过。
- [ ] 引擎 editor/headless 加载通过。
- [ ] 峰值同屏怪物下移动、技能和 UI 仍响应。
- [ ] PC 和至少一台目标手机完成完整流程试玩。
- [ ] 已知问题和验收截图已归档。
